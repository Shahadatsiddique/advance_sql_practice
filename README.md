## Database Tables

The practice exercises use a Library Management System with these tables:

* `Books` — book details and inventory availability
* `Members` — library member information
* `Issued_Books` — book issue records and member relationships
* `Fines` — fine records associated with issued books

## How to Run the SQL Files

1. Install MySQL Server and MySQL Workbench.
2. Download or clone this repository.
3. Review the selected SQL file before executing it.
4. Create and populate the required practice database using the appropriate setup script.
5. Open the SQL file in MySQL Workbench and select the practice database.
6. Execute the queries and review the output.

**Important:** Run setup scripts only against a dedicated practice database. Review any `DROP`, `DELETE`, or other data-modifying statements before execution. Do not run a setup script against an existing database containing important data.
